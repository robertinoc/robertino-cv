# Fonts embedded in the PDF

Static instances downloaded from Google Fonts (WOFF containers, TrueType outlines).
Both families are licensed under the SIL Open Font License 1.1, which permits embedding in documents.

- Sora — https://fonts.google.com/specimen/Sora (SemiBold 600, Bold 700)
- Inter — https://fonts.google.com/specimen/Inter (Regular 400, Medium 500, SemiBold 600, Italic 400)

They mirror the web page's type system so the PDF and the site share one look.
